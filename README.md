# Magnify Media

Premium Next.js 15 rebuild for Magnify Media: multi-page agency website with reusable sections, dynamic service/work/case-study/blog routes, Three.js hero, motion system, SEO routes, Docker, and CI deployment checks.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run typecheck`

Additional Magnify Media 2.0 architecture and deployment notes are available in [`docs/magnify-2.md`](docs/magnify-2.md).
