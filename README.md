# Magnify Media

Premium Next.js 15 website for Magnify Media: a multi-page agency experience with strategic service positioning, story-driven case studies, an interactive Three.js hero, polished motion primitives, accessible SEO routes, and deployment-oriented checks.

## Experience principles

- Cinematic hero with a performance-aware WebGL visual and clear conversion paths.
- Growth Engine narrative connecting brand gravity, AI content intelligence, and revenue telemetry.
- Services positioned around executive outcomes rather than generic marketing cards.
- AI Command Center section to communicate the operating system behind campaigns.
- Case studies structured around problem, strategy, execution, and result.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```
